# DAYA · Демонстрация полевых продаж

Публичная браузерная демонстрация с вымышленными данными. Сохранение — только в IndexedDB посетителя, без общего сервера и рабочей авторизации. Не вводите реальные сведения клиентов.

Собирается командой `npm run build:pages` из приватного репозитория Daya, папки field-sales. Исходный PDF, внутренняя документация и локальные базы сюда не включены.
